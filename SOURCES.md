# Компоненты и источники

Пакет предназначен для Computer Tycoon v0.9.9.16, Windows x64.

* BepInEx 6 для Unity IL2CPP x64, build 788, 6.0.0-be.788+5b766a3.
  [Проект](https://github.com/BepInEx/BepInEx),
  [исходники поставляемой версии](https://github.com/BepInEx/BepInEx/tree/5b766a3),
  [архив исходников](https://github.com/BepInEx/BepInEx/archive/5b766a3.zip).
  Лицензия: `Licenses/BepInEx-LGPL-2.1.txt`.
* Computer Tycoon Language Packs v0.1.1 — Nameland и участники проекта.
  [Проект и исходники](https://github.com/Nameland/computer-tycoon-language-pack/tree/v0.1.1),
  коммит `e51f80c20a8adf04a4c2766bb8440b21cfa819b2`.
  Лицензия кода и уведомление о содержимом игры:
  `Licenses/LanguageMod-MIT-LICENSE.txt` и `Licenses/LanguageMod-NOTICE.md`.
* [UnityDoorstop](https://github.com/NeighTools/UnityDoorstop).
  Лицензия: `Licenses/UNITY-DOORSTOP-LICENSE.txt`.
* [.NET Runtime 6.0.7](https://github.com/dotnet/runtime/tree/v6.0.7).
  Лицензия и уведомления: `Licenses/DOTNET-LICENSE.txt`
  и `Licenses/DOTNET-THIRD-PARTY-NOTICES.txt`.

Оригинальные DLL загрузчика и языкового мода сохранены без изменений.
Русский словарь находится в `languages/ru.json`; установленные пути перечислены
в `package_manifest.json`. Пользовательские имена и исходные файлы игры
в пакет не включены. У каждого компонента сохраняются его собственные условия;
единая лицензия на все содержимое архива не назначается.
