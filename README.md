# Computer Tycoon — русификатор

Русский язык для **Computer Tycoon v0.9.9.16 · Windows x64**.

## [⬇ Скачать русификатор — ZIP, 35 МБ](https://github.com/lucinis/Computer-Tycoon-ru-v0.9.9.16/releases/latest/download/ComputerTycoon_RU_09916_Install.zip)

[Страница выпусков](https://github.com/lucinis/Computer-Tycoon-ru-v0.9.9.16/releases) · [Инструкция](INSTALL_RU.txt)

В архиве уже есть BepInEx, ComputerTycoon.LanguageMod, русский `ru.json`
и настройки. Дополнительное окно консоли отключено.

## Установка

1. Закрой игру и распакуй скачанный ZIP.
2. Открой папку игры, в которой находится `Computer Tycoon.exe`.
3. Скопируй **всё содержимое `Files_to_game`** в эту папку.
4. При обновлении нашего русификатора объедини папки и подтверди замену файлов.
5. Запусти игру. Если русский не включился, нажми **F8** и выбери **«Русский»**.

Копируй содержимое `Files_to_game`, сохраняя вложенные папки.
При первом запуске BepInEx может несколько минут готовить библиотеки;
для первоначальной подготовки может потребоваться интернет.
Сам перевод работает локально.

## Что переведено

Интерфейс, настройки, подсказки, обучение, описания технологий и уведомления
из доступного языкового шаблона. Пакет 03 содержит **7 067 переведённых записей**
и 132 правила для меняющихся строк. Ещё одна запись сохраняет служебный
заполнитель имени компании.

**Надписи на изображениях превью карт и оригинальный журнал изменений пока
остаются в исходном виде.** Полный охват всех экранов и размещение длинного
текста ещё требуют проверки в игре.

## Состав архива

* `Files_to_game` — готовые файлы для установки в игру.
* `INSTALL_RU.txt` — короткая инструкция установки.
* `Licenses` и `SOURCES.md` — лицензии компонентов и ссылки на исходники.

## Если возникла проблема

Создай [обращение](https://github.com/lucinis/Computer-Tycoon-ru-v0.9.9.16/issues), укажи версию игры и приложи скриншот.
При ошибке запуска пригодится файл `BepInEx/LogOutput.log`.

Для временного отключения закрой игру и переименуй `winhttp.dll`
в `winhttp.dll.disabled`. Это отключает BepInEx и все моды, работающие через него.

Файлы репозитория также содержат отдельный словарь `languages/ru.json`
для редактирования перевода.

Архив собирается из закреплённых версий компонентов с проверкой SHA-256.
Публикация запускается при изменении `release.json` в ветке `main`;
готовые файлы находятся в Releases.
